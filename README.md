# NexusLeave Enterprise
A modern, glass‑morphic, client‑side **Leave Management System** demo.

- **Employee view** – apply for paid, sick, casual, or custom leave.  
- **Admin view** – approve / reject requests, see balances, audit log.  
- **Zero‑setup** – data persisted in browser `localStorage`.  

Open `index.html` directly, or host it with any static web server  
(e.g. `python -m http.server 8080`).  

[Live demo on GitHub Pages](https://<your‑username>.github.io/nexusleave/)
